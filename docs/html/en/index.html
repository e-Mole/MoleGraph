MoleGraph - On-line tools

🇨🇿 Přepnout do češtiny
A hub for MoleGraph measuring system online tools. All listed applications run locally and securely right in your web browser.

For Students

Color Laboratory
Color analysis and simulation. A tool for analyzing data measured by the MoleGraph sensor, which uses a precise TCS34725 color sensor for detection. For the laboratory to function correctly, the uploaded data file (.CSV) must contain Hue, Saturation, and Lightness values. Students will familiarize themselves with basic models (HSV, RGB, CMYK, CIELAB), can explore measurements of emitted and reflected light, and use a module for simulating color mixing and calculating the deviation of real samples (ΔE).

For Teachers and Developers

Did you know? You can easily customize the sensor menu in the MoleGraph application. Everything is controlled by the sensors.json configuration file. The editors provided here allow you to visually modify this file and subsequently replace the original one in the sensors folder.

Sensor Editor
(For Teachers)
Simplify work for students. Allows you to hide unused sensors, modify texts displayed in the application, or change calibration values. Ideal if you want to show only physically available sensors to younger children (e.g., primary school).
JSON Editor
(For Developers)
Complete control. A full-featured editor for advanced modifications at the developer level. An essential tool if you have customized the MoleGraphAuto firmware with your own sensors and need to add them correctly to the application.
