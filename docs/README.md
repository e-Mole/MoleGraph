# MoleGraph Documentation

Welcome to the MoleGraph documentation directory. To keep things organized, our documentation is divided into logical sub-folders depending on what you are looking for.

## Directory Structure

- 📂 **`/architecture`**  
  Contains technical documentation, UML diagrams, class relations, execution flows, and communication protocols. **Target audience:** Developers and contributors modifying the software or Arduino firmware.

- 📂 **`/troubleshooting`**  
  Contains practical step-by-step guides for solving known hardware and software issues (e.g., resolving Arduino Nano clone upload freezes). **Target audience:** Teachers, makers, and end-users building the project.

- 📂 **`/img_readme`**  
  Contains graphical assets and images used in the main project README file.

- 📄 **`index.html`** & 📂 **`/html`**  
  Serves as a hub (signpost) for various online interactive tools for the MoleGraph system.  
  **Target audience:** Students, teachers, and developers interacting with MoleGraph via a web browser. Accessible online via GitHub Pages.

---
*💡 **Note for Czech users:** Czech versions of the guides and documentation (where available) are located in the respective folders and use the `.cs.md` extension. The web tools automatically detect your browser language.*
