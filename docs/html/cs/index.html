Věděli jste? Nabídku čidel v aplikaci MoleGraph si můžete snadno přizpůsobit. Vše řídí konfigurační soubor sensors.json. Zde připravené editory vám umožní tento soubor snadno upravit a následně jím nahradit ten původní ve složce sensors.

Sensor Editor
(Pro učitele)
Zjednodušte žákům práci. Umožňuje skrýt nepoužívaná čidla, upravit texty zobrazené v aplikaci nebo změnit kalibrační hodnoty. Ideální, pokud chcete menším dětem (např. 1. stupeň ZŠ) zobrazit jen fyzicky dostupná čidla.
JSON Editor
(Pro vývojáře)
Kompletní kontrola. Plnohodnotný editor pro pokročilé úpravy na vývojářské úrovni. Nezbytný nástroj, pokud máte upravený firmware MoleGraphAuto s vlastními čidly a potřebujete je korektně přidat do aplikace.
Color Laboratory
Hravé experimenty. Interaktivní prostředí pro žáky, kde mohou zkoumat barvy, hrát si s jejich mícháním a objevovat fyzikální zákonitosti zábavnou formou.
