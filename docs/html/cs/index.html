Rozcestník online nástrojů pro měřicí systém MoleGraph. Všechny uvedené aplikace běží lokálně a bezpečně přímo ve vašem internetovém prohlížeči.

Pro žáky

Color Laboratory
Analýza a simulace barev. Nástroj pro analýzu CSV dat naměřených senzorem MoleGraph[cite: 1]. Umožňuje zkoumat měření vyzařovaného světla (např. z monitoru) i odraženého světla (z papíru)[cite: 1]. Žáci se zde seznámí se základními barevnými modely jako jsou HSV, RGB, CMYK či CIELAB a mohou využít modul pro simulaci míchání barev a výpočet odchylky reálných vzorků (ΔE)[cite: 1].

Pro učitele a vývojáře

Věděli jste? Nabídku čidel v aplikaci MoleGraph si můžete snadno přizpůsobit. Vše řídí konfigurační soubor sensors.json. Zde připravené editory vám umožní tento soubor vizuálně upravit a následně jím nahradit ten původní ve složce sensors.

Sensor Editor
(Pro učitele)
Zjednodušte žákům práci. Umožňuje skrýt nepoužívaná čidla, upravit texty zobrazené v aplikaci nebo změnit kalibrační hodnoty. Ideální, pokud chcete menším dětem (např. 1. stupeň ZŠ) zobrazit jen fyzicky dostupná čidla.
JSON Editor
(Pro vývojáře)
Kompletní kontrola. Plnohodnotný editor pro pokročilé úpravy na vývojářské úrovni. Nezbytný nástroj, pokud máte upravený firmware MoleGraphAuto s vlastními čidly a potřebujete je korektně přidat do aplikace.
